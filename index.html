What this web version can do

Useful tools that can safely run as a static site, without a hosted downloader backend.

✓ YouTube thumbnails

Preview max resolution, standard and high-quality thumbnail variants, then download available images.

✓ Local video frame extraction

Extract frames from files you select, at your chosen FPS and optional time range. Export selected images in a ZIP.

✓ Batch exports

Process up to 25 local video files in sequence. The ZIP contains per-video folders, metadata JSON, and batch manifests.

Desktop-only capability

Downloading full videos from YouTube and other supported sites requires the Frex Python/yt-dlp desktop application. A static GitHub Pages website cannot run that local Python backend.

Privacy note: Local video files are processed inside your browser tab. Thumbnail requests go to YouTube's image host. Avoid selecting private or sensitive files on a shared device.
